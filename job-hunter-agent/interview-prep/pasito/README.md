## Format (rehearse it every time)
1. Restate the problem and ask about edge cases (empty input, duplicates, negatives, case).
2. State the brute force and its cost, out loud.
3. Name the better pattern, then code it while talking.
4. Walk through one example by hand, then the edge cases.
5. State the time and space complexity.
